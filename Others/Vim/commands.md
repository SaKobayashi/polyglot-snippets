# Vimの基本操作
| コマンド | 説明 | 使用例 |
|-----|-----|-----|
| ```vim　<ファイル名>``` | vim起動 |
| ```:q``` | 終了 |
| ```:q!``` | 強制終了 |
| ```:w``` | 上書き保存 |
| ```:wq``` | 上書き保存して終了 |
| ```i``` | 挿入モード |
| ```Esc``` | ノーマルモード |
| ```y``` | コピー |
| ```p``` | ペースト |
| ```/ <文字列>``` | 下方向検索 |
| ```? <文字列>``` | 上方向検索 |
