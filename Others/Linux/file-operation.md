# 基本コマンド
| コマンド | 説明 | 使用例 |
|-----|-----|-----|
|```cd```|ディレクトリ移動|```cd <パス>```|
|```ls```|ディレクトリ内容表示|```ls <パス>```|
|```pwd```|現在のパスを表示|```pwd```|
|```cat```|ファイル内容表示|```cat <ファイル名>```|
|```mv```|ファイル移動|```mv <移動元パス> <移動先パス>```|
|```mkdir```|ディレクトリ作成|```mkdir <ディレクトリ名>```|
|```touch```|ファイル作成|```touch <ファイル名>```|
|```rm```|ディレクトリ・ファイル削除|```rm <ディレクトリ名>```|

# ディレクトリ表現
## ディレクトリ例
```
/home/user
├─ projects
│   ├─ app
│   │   ├─ src
│   │   └─ tests
│   └─ tools
└─ documents
    ├─ work
    └─ private
```

## 現在地
```/home/user/projects/app/src```

## 使用例（cd）
| コマンド | 説明 | 使用後のディレクトリ |
|-----|-----|-----|
| ```.``` | カレントディレクトリ | ```/home/user/projects/app/src``` |
| ```..``` | 1つ上へ | ```/home/user/projects/app``` |
| ```../..``` | 2つ上へ | ```/home/user/projects``` |
| ```../../tools``` | 2つ上に戻って tools へ | ```/home/user/projects/tools``` |
| ```~``` | ホームディレクトリ | ```/home/user``` |
| ```~/projects/app/tests``` | 絶対パス（~）から移動 | ```/home/user/projects/app/tests``` |
| ```-``` | 直前のディレクトリへ | ```/home/user``` |
| ```/``` | ルートへ | ```/``` |
