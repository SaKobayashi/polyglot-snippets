# Git用語集

## リポジトリ
Gitがファイルの変更履歴を管理・保存する場所。

## リモートリポジトリ
GitHub や GitLab などのサーバ上にあるリポジトリ。
チームで変更履歴を共有するために使う。

## ローカルリポジトリ
自分のPC上にあるリポジトリ。
コミットやブランチ操作は基本的にここで行う。

## インデックス(ステージ)
次のコミットに含める変更内容を一時的に登録する場所。
git add で追加される。

## コミット
インデックスにある内容を確定して履歴として保存すること。

## HEAD
現在自分が作業している位置を指すポインタ。
通常は「現在のブランチの最新コミット」を指している。

## ブランチ
作業履歴の流れを分岐させるための仕組み。
他の作業に影響を与えずに開発できる。

### origin
リモートリポジトリのこと。
リモートリポジトリのデフォルト名。
ブランチではない。

### main(master)
プロジェクトのメインとなるブランチ。

## マージ
別のブランチの内容を取り込んで統合すること。

## コンフリクト（競合）
同じ場所を別々に変更したため、Git が自動でまとめられない状態。

## .git
Gitの管理情報（履歴・設定など）が入っている隠しフォルダ。
ここがあるディレクトリが「Git管理されている」状態。
