# 作業の流れ(ブランチ作成～プルリク)
## 1. 作業元ブランチ（main など）に切り替えて最新化
```
git switch main
git pull
```

## 2. 作業ブランチを作成して、そのブランチに切り替える
```
git switch -c <作業ブランチ名>
```

## 3. 作業する

## 4. 作業内容（変更した内容）を確認する
### 作業したファイル、追加したファイル、削除したファイルが正しいかどうか確認
```
git status
```

## 5. 変更をステージングエリアに追加する
すべてをステージング
```
git add -A
```

ファイル単位でステージング
```
git add <file>
```

## 6. コミットする
```
git commit -m "コメント"
```

## 7. リモートリポジトリに push する
```初回
git push -u origin <作業ブランチ名>
```

```2回目以降
git push
```

## 8. GitHub などで Pull Request を作成する

---
# 日を跨いだりして、他の作業者の変更をマージしたいとき
## pull(fetch + merge)する
```
git pull <リモート名> <作業ブランチ名>
```
